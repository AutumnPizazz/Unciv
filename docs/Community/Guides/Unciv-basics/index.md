## Terms / Abbreviations

Chinese players often use shorthand names (e.g. "巴弓" for Babylonian Bowman). This page only lists special abbreviations/terms.

### English abbreviations

| Abbr | Full | Meaning |
| :-: | :-: | :-: |
| T | Turn | Turn |
| UU | Unique Unit | Unique unit |
| UA | Unique Ability | Unique ability |
| UB | Unique Building | Unique building |
| UI | Unique Improvement | Unique improvement |
| MOD | Modification | A game extension, i.e. a mod |
| TJ | — | "Eunuch" (tj) — quitting a game before finishing |
| G | Gold | Gold / cash |
| AI | artificial intelligence | Computer players |
| RA | Research Agreement | Research agreement |
| GPT | Gold Per Turn | Gold per turn |
| SL | Save/Load (Ciallo~) | Saving and loading |

### Common terms

| Term | Meaning |
| :-: | :-: |
| 爆铺 (wide) | Many cities, developing national strength through numbers |
| 精铺 (tall) | Few cities, focusing on a small number of high-quality cities |
| 魔王流 (demon king) | Pushing forward while tanking lots of unhappiness |
| 蘑菇 (mushroom) | An AI/player that doesn't expand, just develops — like a mushroom waiting to be picked |
| 种田 (farming) | Focusing on developing your own strength |
| 骗宣 (trick-war) | Trading per-turn resources for an AI's cash, then declaring war so you keep the cash and the AI gets nothing |
| 买宣 (buy-war) | Paying an AI to declare war on someone else |
| 背刺 (backstab) | Turning hostile/declaring war after long friendship or neutrality |
| 开门 (opening) | Unlocking a policy tree (with its opener effect) |
| 关门 (closing) | Completing all policies of a tree (with its finisher effect) |
| 刮刮乐 (scratch lotto) | Repeatedly pillaging by having workers repair improvements |
| 勾引大法 (lure trick) | Using a worker to bait enemy units onto a tile, then surrounding them |
| 自主左二 etc. | Shorthand for the 2nd policy from the left/middle/right of a policy tree |
| 锤子 (hammer) | Production |
| 瓶子 (bottle) | Science |
| 鸽子 (dove) | Faith |
| 坐城 (sit city) | Founding a city |
