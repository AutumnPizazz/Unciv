# CoeHarMod Introduction

## About CoeHarMod

CoeHarMod (和合共生, "Harmony and Coexistence") is a large ruleset mod dedicated to optimizing and expanding the Unciv game experience.

### Core philosophy

> "和合共生，万物各得其和以生，各得其养以成" — Harmony and coexistence: all things live in their harmony and grow in their nourishment.

The mod aims to provide a richer and more diverse game experience while maintaining game balance.

### Installation

1. Download the latest mod files
2. Put the mod folder into the game's `mods/` directory
3. Enable CoeHarMod in game settings
4. Start a new game to play

::: warning Note

- The mod only supports new games; it is incompatible with existing saves
- Standard speed is recommended for the best experience
- Some features require specific modes (e.g. Secret Societies)

:::
