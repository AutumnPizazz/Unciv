# UncivCN 与上游差异对照

| 功能 | 上游 Unciv | UncivCN |
|---|---|---|
| 联机方式 | 动态回合（严格顺序制） | 动态回合 + **轮询联机**（时间片轮转，等待上限数秒） |
| 联机服务器 | 官方服务器 | 默认 `sp.unciv.cn:30123` |
| 联机公平性 | — | 随机数读档可变功能联机时禁用 |
| 地图类型 | 标准地图 | + **三种镜像地图**（资源对称）+ **环形地图**（取消半径奇偶限制） |
| 模组脚本 | 纯 JSON | + **Lua 脚本**（Unique 触发 / 生命周期钩子 / ctx API） |
| 模组 JSON | 整对象替换 / 基础 `_mergeAction` | **MergeAction 字段级合并扩展**、新增 Countables 参数 |
| 模组检查器 | 检查 JSON | + 筛查 Lua 错误 |
| 地块归属 | 无 | **tile-claim**（城市宣称/交换地块） |
| 人口管理 | 手动锁定 | + **自动锁定按钮**（永久切换不锁/锁人口） |
| 地图标注 | 无 | **单位钉 / 地图钉**（备注数据存 `{存档名}_notes`） |
| 开局配置 | 手动设置 | **设置导出/导入剪贴板** |
| 存档兼容 | 无隔离 | **版本隔离**（旧版无法加载新版存档） |
| 内置模组 | 无 | 4.21.0.1 曾自带 UCCC；4.21.5.1 起撤销，不再打包任何模组 |
| 本地化 | 多语言 | + 完整中文本地化（含 Unique 翻译） |
| 游戏内容 | 同步上游 | 始终跟进上游最新版本（当前基于 4.21.5） |

## 说明

- UncivCN 全部新功能均为**增量实现**，不修改上游既有行为；关闭相关选项后与上游一致
- 中文界面与文档为本分支的一等公民：全部 Unique、UI 字符串均有中文翻译
- 版本号 = 上游版本 + `.1` 后缀，可通过 [更新日志](./更新日志) 追踪演进
