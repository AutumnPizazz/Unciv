# 隐私政策

本政策适用于 UncivCN 社区提供的服务：本文档站、社区下载服务器与社区联机服务器。这些服务由社区维护者以个人身份自建、自维护，**与 Unciv 上游项目及其开发者（yairm210 团队，<https://github.com/yairm210/Unciv>）无关，也不代表任何官方服务**。社区维护者是这些服务的数据控制者。

问题咨询、数据导出与删除请求：[QQ 群](https://qm.qq.com/q/j92c3iUnZ0) 或 [GitHub Issues](https://github.com/AutumnPizazz/Unciv/issues)。

## 我们会存储什么

| 数据 | 用途 | 保存时长 |
| --- | --- | --- |
| 玩家 ID 与密码哈希 | 登录联机服务器。玩家 ID 由游戏客户端生成，密码只以加盐哈希保存 | 直到你请求删除账号 |
| 最后活跃时间 | 显示在线状态、清理长期不用的数据 | 直到删除账号 |
| IP 地址 | 防滥用与限流。默认只保留网段（IPv4 `/24`、IPv6 `/48`） | 默认 30 天，到期自动清空；服务器可以配置为完全不存 |
| 联机存档 | 供同局的其他玩家获取当前回合 | 长期无人使用的对局会在服务器空间紧张时加密归档到别处；归档的对局仍可按请求恢复，也可以请求彻底删除 |
| 访问日志（IP、User-Agent） | 安全防护与故障排查 | 在服务器上短期保留，不对外提供 |

密码以 `scrypt` 哈希保存，每个账号使用独立随机盐：包括管理员在内任何人都无法还原出明文，管理员只能重置密码。

## 我们不会存储什么

- 不收集真实姓名、证件号、手机号或邮箱，本服务不要求提供身份信息。
- 不收集支付信息与广告标识：这些服务免费且非商业运营。
- 不会出售或向第三方提供数据；文档站不接入统计或追踪脚本。

## 你的选择

- **换用其他服务器**：在游戏「选项 → 高级」中设置自己的联机服务器地址，也可以在那里导入自己的玩家 ID。
- **导出或删除数据**：在 QQ 群或 GitHub Issues 中提出，我们会提供存档导出并删除你的账号与数据。
- 游戏的其他数据（设置、单机存档）都保存在你自己的设备上，服务器只能看到联机客户端上传的内容。
- 未成年人未经监护人同意注册的，可联系我们删除账号。

## 第三方

- 文档站托管在 GitHub Pages，访问时也会经过 GitHub 的服务器。
- 模组与安装包可能从你在游戏里配置的镜像下载，这些服务有各自的隐私政策。
- 视可用性，服务器可能部署在中国大陆以外，数据在服务器所在地处理。

## 安全与限制

我们使用 HTTPS、密码哈希与访问控制，但这些是由志愿者维护的服务，按「现状」提供。我们无法承诺可用性、绝对保密或数据永不丢失，请为你重视的存档保留本地备份。

本政策的变更会记录在[更新日志](/zh/UncivCN/Changelog)中；服务的使用规则见[用户协议](/zh/Terms-of-Service)。
