# 用户协议

本协议适用于 UncivCN 社区提供的服务：社区联机服务器、社区下载服务器与本文档站。这些服务由社区维护者以个人身份自建、自维护，免费且非商业。它们**不是官方服务**：Unciv 游戏由上游团队（https://github.com/yairm210/Unciv）开发，上游团队没有参与、也不对这些服务负责。使用任一服务即表示你同意本协议与[隐私政策](/zh/Privacy-Policy)。

## 1. 服务内容

- **联机服务器**：存档上传与下载、同步回合，以及可选的游戏内聊天。
- **下载服务器**：提供 UncivCN 的版本清单与下载直链（安装包本身托管在 GitHub Release 上）。
- **文档站**：项目文档与更新日志。

以上都是免费的技术设施，不销售任何付费内容、订阅或游戏道具。

## 2. 账号

- 玩家 ID 由游戏客户端生成。请妥善保管密码，不要与其他网站使用相同的密码。
- 服务器可能采用审核制注册：新账号需经管理员确认后才能使用联机功能。
- 请勿共享、转借或出售账号；账号下的一切行为视为账号持有人所为。
- 如怀疑账号被盗用，请及时联系我们。

## 3. 使用规范

禁止：

- 发布或上传违法违规、仇恨、骚扰内容（包括聊天消息与存档文件内的文本）；
- 上传他人存档、外挂或恶意数据；
- 对服务器进行攻击、扫描、爬虫、超量请求，或绕过限流；
- 利用本服务从事商业经营；
- 冒充维护者、上游项目或其他玩家。

视情节，我们可能警告、删除数据、封禁账号，严重时向执法机关报告。

## 4. 存档与数据

- 联机服务器上的存档用于在玩家之间传递回合，请始终保留自己的本地备份。
- 因法律合规要求、不可抗力、硬件故障或服务调整，我们可能暂停服务或清空数据。我们会尽可能提前在社区公告并提供存档导出通道，但不对数据丢失承担赔偿责任。
- 服务变更或关停时，请通过 QQ 群或 GitHub Issues 联系我们导出存档。

服务按「现状」提供，不保证可用性、连续性与数据完整性。玩家之间的纠纷（包括游戏内的行为）与我们无关。我们不对间接损失负责；适用法律不允许限制的责任不受本条影响。

## 6. 变更与终止

- 我们可能随时调整、暂停或终止部分或全部服务，尤其是为满足法律合规要求时。
- 本协议可能更新，更新会在文档站与更新日志中说明；继续使用即视为接受更新后的条款。
- 本协议适用服务器部署地的法律；发生争议时我们先通过沟通解决。
